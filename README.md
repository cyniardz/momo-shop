# momo.

**작은 친구가 만드는 커다란 행복.**

빨간 털모자를 쓴 아기곰 캐릭터 **모모**의 굿즈 쇼핑몰입니다.
PC에서는 왼쪽에 이벤트·검색·퀵메뉴 패널을, 오른쪽에 모바일 쇼핑 화면을 나란히 보여 주는 **일체형 페이지**로 만들었습니다.

- Live: https://momo-bearstudio.vercel.app

## 페이지

| 파일 | 내용 |
| --- | --- |
| `index.html` | 메인 (슬라이드, 베스트, 타임세일, 선물 기획전, 순위, 리뷰) |
| `list.html` | 상품 목록 (카테고리, 가격대·판매 형태·배송 필터, 정렬, 페이지) |
| `detail.html?id=번호` | 상품 상세 (갤러리, 옵션, 수량, 선물포장, 상세·스펙/KC·배송/교환·후기 탭, 연관 상품) |
| `about.html` | 캐릭터 소개 (프로필, 모모의 하루 16컷) |
| `cart.html` | 장바구니 (무료배송 기준, 선물포장, 예약판매 안내) |
| `event.html` | 기획전 · 이벤트 |
| `cs.html` | 고객센터 (배송, 해외배송, 교환·반품, FAQ) |
| `wish.html` | 위시리스트 |
| `404.html` | 에러 페이지 |

## 구조

- `common.js` 헤더·푸터, 왼쪽 패널, 검색, 일체형 모달, 로그인·회원가입, 찜, 장바구니를 모든 페이지에 넣습니다.
- `data/product.json` 상품 16개, 캐릭터, 갤러리, 배송 정책
- `data/event.json` 모달, 이벤트 패널, 타임세일, 쿠폰, 기획전
- 빌드 도구 없이 HTML · CSS · JavaScript만 사용했습니다.

## 참고

- 로그인·회원가입·찜·장바구니는 브라우저(localStorage)에만 저장되는 시연용입니다. 주문·결제는 포트폴리오 범위 밖입니다.
- 캐릭터 설정, 가격, 후기는 임시 데이터입니다.
- JSON을 불러오기 때문에 로컬에서는 Live Server 같은 서버로 열어야 합니다.
